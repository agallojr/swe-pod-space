- **The git gate fails open on this node, so smoke S6 and S7 fail.** The
  runner registers the gate as a PreToolUse hook, with the gate file itself
  as the command (runner.sh at f128c46, line 751), so the gate runs by its
  shebang. agent-mesh bbd19a2 `hooks/git-gate.py` line 1 is `#!/usr/bin/env
  /usr/bin/python3`, and on this node that interpreter is Python 3.6.8. Line
  39, `from __future__ import annotations`, needs Python 3.7 or later. So
  the gate stops at startup with a SyntaxError, exit status 1, and prints no
  decision. Claude Code treats that exit status as a non-blocking hook
  error, and the call goes on under the Bash allow rule.

    gate denies the commit, as it should.

    `.git`.

    the case folder. Nothing was pushed, and the probe clone is scratch.
  - Fixing this needs a change to the runner (how it invokes the gate), to
    the gate (its shebang or its Python floor), or to the node's interpreter.
    All three are outside the test lane, so this is for the lead.

  space 33c829f, whose runner also invoked the gate by its shebang, and the
  gate at agent-mesh 1367f65 fails the same way under Python 3.6.8. Round 1
