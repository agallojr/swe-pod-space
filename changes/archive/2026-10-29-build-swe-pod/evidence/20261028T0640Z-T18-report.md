What changed, by finding:

1. `commands()` now reads DESK lines from reply text and subagent results
   (as before), from the contents of files written with Write or Edit, and
   from each Bash call: its output's DESK lines when the command itself
   holds DESK text, else the DESK text its `echo`/`printf` commands and
   heredoc bodies print or write, with simple shell variables set in the
   same command expanded. Heredoc bodies and echo text are never taken as
   commands; operators are split only outside quotes, so an echoed
   `fetch && rev-parse` is one DESK line that `git_ops` splits, not a real
   call. DESK lines of a file the agent only shows (`cat` of a report) are
