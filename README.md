# swe-pod-space

Project Space for `proj:swe-pod`: developing the SWE Pod, a spec-first
software engineering process run by a pod of agents. Specs, plans, ledgers,
reviews, evidence and project-level tests live here. The deliverables live in
the code repos `pod.yaml` names: `agallojr/swe-pod` (the SWE Pod product) and
`agallojr/agent-mesh` (the Agent Mesh changes it needs).

Start with `AGENTS.md`, then `STATUS.md`.
